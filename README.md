# GIF Редактор

Интерфейс рассчитан на слайд 16:9 (рабочая область 1440 × 810) и целиком масштабируется под окно или iframe без прокрутки. Для Genially вставьте ссылку https://galmizmaria-beep.github.io/gif-1/ и растяните область встраивания на весь слайд 16:9. При других пропорциях весь редактор остаётся виден с полями по краям. Настройки, обрезка и кнопки сохранения находятся внутри рабочей области. Подпись с правами размещена сразу под названием редактора в верхней части слайда. Окно предпросмотра увеличено до 1008 × 468 пикселей в базовом размере.

Откройте `index.html` двойным щелчком в современном браузере. Файл `гиф редактор.txt` содержит тот же HTML-код для вставки на площадку, поддерживающую HTML, JavaScript и Web Workers.

- Вкладка «Загрузить видео» создаёт GIF из видео.
- Вкладка «Загрузить GIF» открывает готовую анимацию, в том числе ранее сохранённую этим редактором.
- «Авто» подбирает цвет и силу удаления фона и сразу применяет их. Ползунок самостоятельно удаляет фон без нажатия «Авто»: при движении включает удаление, определяет цвет текущего кадра (или использует вручную выбранный цвет) и сразу перерисовывает предпросмотр, не дожидаясь отпускания ползунка или обработки GIF. Если автоопределение не нашло цвет, ручной режим использует непрозрачную границу изображения.
- Кнопки «Назад» и «Вперёд» отменяют и возвращают настройки фона, цвета, обрезки, качества и сжатия. Одно перемещение ползунка считается одним действием. Доступны Ctrl/⌘ Z и Ctrl/⌘ Shift Z (также Ctrl/⌘ Y). После нового действия отменённая ветка истории удаляется; сохраняются последние 100 состояний.
- «Сброс — новый файл» очищает загруженный файл, результат и историю, возвращает исходные настройки и позволяет выбрать новое видео или GIF.
- «✂ Ножницы» открывают пунктирную квадратную рамку. Передвигайте её мышью или стрелками (Shift — 10 пикселей), меняйте размер за края и углы либо нарисуйте новую область снаружи рамки. «✓ Готово» показывает обрезанный предпросмотр. При создании GIF сохраняется только область внутри рамки для всех кадров видео или GIF, в том числе если рамка ещё открыта. «Сбросить обрезку» возвращает полный кадр; обрезка поддерживает отмену и повтор. Качество задаёт максимальную сторону результата без увеличения исходной области.
- После загрузки можно выбрать начало и конец фрагмента, размер и сжатие, включить или выключить удаление фона.
- Для GIF удаление фона по умолчанию выключено. Прозрачность и длительность отдельных кадров сохраняются; границы обрезки округляются до точности формата GIF — 10 мс. Сохранённая анимация повторяется бесконечно.
- Для экспорта используется общая палитра, подобранная по кадрам всего выбранного фрагмента, чтобы постоянные цвета не менялись от кадра к кадру. Прозрачность кодируется по альфа-каналу с отдельным индексом палитры: непрозрачные цвета, включая пурпурный, больше не становятся случайно прозрачными. Во время обработки предпросмотр продолжает воспроизводить анимацию выбранного размера; экспорт читает кадры из отдельного видеоэлемента; готовый GIF показывается после загрузки изображения.
- При выборе качества или сжатия предпросмотр сразу меняет разрешение, затем автоматически создаётся и показывается итоговый GIF. Под предпросмотром указаны размеры в пикселях; после сборки показан именно файл для скачивания. Исходные изображения меньшего размера не увеличиваются.
- Нажмите «Обработать и создать гиф», затем «СКАЧАТЬ GIF». Для нового варианта измените настройки и обработайте файл ещё раз.
- Сохранённую GIF можно снова выбрать во вкладке «Загрузить GIF».

Обработка выполняется локально в браузере. Кодировщик и декодировщик встроены в HTML. Используются системные шрифты без внешних загрузок.

Размер загрузки ограничен 100 МБ. Для декодированных кадров загружаемого GIF действует ограничение памяти 160 МБ и 3000 кадров. Экспорт кодирует кадры по очереди, поэтому прежний порог 256 МБ для суммы несжатых кадров больше не блокирует высокое качество. Размер готового GIF не ограничен 5 или 10 МБ; фактический предел зависит от доступной памяти браузера. Режимы «Умеренное» и «Сильное» усиливают сжатие без гарантии размера; итоговый размер показан после обработки. Если площадка назначения принимает файлы только до 5 МБ, её ограничение сохраняется.

Удаление фона автоматически определяет цвет по непрозрачным краям. У GIF с прозрачными краями алгоритм ищет остатки зелёного внутри кадра. Можно вручную выбрать цвет для удаления; зелёная примесь подавляется только около прозрачных участков при включённой опции «Убирать зелёный ореол по краям». На высокой силе захватываются более тёмные и светлые оттенки выбранного цвета. Результат зависит от исходного изображения: для сложных контуров настройте цвет и силу вручную. Формат GIF ограничен палитрой цветов; повторное сохранение может изменить оттенки. Обработка библиотек выполняется в Web Workers: площадка встраивания должна разрешать их запуск из Blob.

Под названием редактора размещено: «Все права защищены и принадлежат Гальмиз Марии Александровне». Лицензии сторонних библиотек сохранены в `THIRD_PARTY_LICENSES.txt` и внутри HTML.

Проверка текущего изменения: `node tests/export.test.mjs` — синтаксис встроенных скриптов, совпадение HTML и TXT, общая палитра, стабильность цветов между кадрами, непрозрачный пурпурный цвет, точная прозрачность, полностью прозрачный кадр, замена кадров, длительности, передача буферов, многоблочный GIF, сохранение холста предпросмотра и обработка ошибок worker. Проверка на предоставленном MP4 (960 × 960, 5,088 с) выполнена в отдельном Chrome: обработка 480 × 480 и 960 × 960, снимки реального воспроизведения, работа предпросмотра во время обработки. Для варианта 480 × 480 сверены все 77 кадров с исходным видео: ошибок прозрачности нет; максимальная средняя ошибка RGB — 4,59 из 255. Сплошные вспышки в тестовом прогоне не воспроизвелись. Отчёты и GIF находятся в artifacts/. Дополнительно исправлены ожидание первого отображаемого кадра для определения фона и равномерный выбор времени кадров.

Для повторения теста: python3 tests/video_server.py /path/to/video.mp4. Сервер доступен только на 127.0.0.1:8765. tests/chrome_check.py подключается к отдельному тестовому Chrome на локальном отладочном порту 9223 и сохраняет отчёт и снимки воспроизведения. Пользовательский профиль браузера не используется.

Проверка смены качества на том же MP4: выбор через меню 320 → 1080 → 480; фактические размеры 320 → 960 → 480 (исходник не увеличивается). Во время экспорта во всех трёх режимах предпросмотр продолжал менять кадры. Сверка 77 кадров среднего качества: ошибок прозрачности нет. Для повторения: `python3 tests/chrome_check.py --mode after --switch`.
